**Personal Profile Web Application** built for
**CSC584 – Individual Assignment 1** using HTML, CSS, Java Servlet and JavaServer Pages (JSP).

The user fills in a profile form, the form is submitted to a Servlet using HTTP POST,
and the Servlet forwards the data to a JSP page that displays the profile.

## Features

- HTML form with six labelled fields: Name, Student ID, Programme, Email, Hobbies, Short Self-Introduction
- Form submitted with `method="POST"` to `ProfileServlet`
- Servlet reads all six submitted values, sets request attributes, and forwards to `profile.jsp`
- JSP displays all submitted information (HTML-escaped for safety)
- Browser validation using HTML `required`, `maxlength`, and `type="email"` attributes
- Simple, responsive mint-themed CSS layout
- No database required

## How It Works

```
index.html (form)  --HTTP POST-->  ProfileServlet.java  --forward-->  profile.jsp (display)
```

The servlet sets UTF-8 encoding before reading the form values. It passes them to
`profile.jsp` using `request.setAttribute(...)` and
`request.getRequestDispatcher("/profile.jsp").forward(request, response)`.

The browser address remains `/PERSONAL_WEB_PROFILE/ProfileServlet` after submission
because forwarding happens inside the server. The displayed page is generated by
`profile.jsp`. Opening `ProfileServlet` with a GET request or opening `profile.jsp`
directly returns the user to the form.

Servlet registration uses `@WebServlet("/ProfileServlet")` (with the servlet name
also specified in the source). The welcome page is configured in `web.xml`.

Input validation is performed by the HTML form in the browser , if there are form that are not filled an indicator will be shown that the form need to be filled first before proceeding to creating profile.
